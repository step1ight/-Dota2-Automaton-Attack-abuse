Абуз мини-игры "Атака Автоматонов" Dota2. 
Скрипт спамит перечень букв которые есть в название героев и предметов, со скоростью 10.000 символов в 1 секунду. 
Нагрузки на ЦП нет, так как скрипт не эмулирует нажатие клавиш, он сразу вводит нужные буквы в системе. С игрой никак не взаимодействует, ОЗУ не читает, вероятность блокировки нулевая.
Написан на Python и скомпилированный в приложение.

Гайд по запуску:
1. Запустить файл Automaton Attack.exe от имени администратора. (Требуется для того чтобы скрипт мог печатать)
2. Зайти в Dota2 --> Мини игра "Атака автоматонов" --> Нажать "Играть" --> Нажать на цифру "1".
3. Для удобства можно поставить в настройках Dota2 "В окне без рамки" чтобы видеть окно скрипта. (Не обязательно)

Цифра "1" на клавиатуре - запуск скрипта. Цифры "2" - остановка скрипта.
